**TA390 v1.3 — ilk genel sürüm / first public release**

TYT MD-UV380 / MD-UV390 için OpenGD77 tabanlı, resmi olmayan telsiz yazılımı, Windows programı ve Android uygulaması.
An unofficial OpenGD77 based firmware for the TYT MD-UV380 / MD-UV390, with a Windows program and an Android app.

| Dosya / File | |
|---|---|
| `TA390_v1.3.zip` | Telsiz yazılımı / Radio firmware |
| `TA390_Kurulum_v1.3.exe` | Windows programı / Windows program (setup) |
| `TA390_v1.3.apk` | Android uygulaması / Android app (USB OTG) |
| `TA390_v1.3_Kullanim_Kilavuzu.pdf` | Kullanım kılavuzu (Türkçe) |
| `TA390_v1.3_User_Manual_EN.pdf` | User manual (English) |
| `SHA256SUMS.txt` | Dosya özetleri / checksums |

**Yüklemeden önce / Before flashing:** Flash, MCU ROM ve Kalibrasyon yedeği alın. / Make Flash, MCU ROM and Calibration backups.

- DMR ses çözücüsü (AMBE) dağıtılmaz; program orijinal TYT donör yazılımını kendi cihazınıza indirip ekler. / The AMBE codec is not distributed; the program downloads the official TYT donor firmware to your own device.
- Windows SmartScreen uyarısı ve Android "bilinmeyen kaynak" izni normaldir (dosyalar ticari imza taşımaz). / SmartScreen and "unknown sources" prompts are expected (the files are not commercially signed).
- Resmi bir OpenGD77 sürümü değildir; ücretsizdir, ticari kullanım yasaktır, garanti verilmez. / Not an official OpenGD77 release; free, no commercial use, no warranty.
